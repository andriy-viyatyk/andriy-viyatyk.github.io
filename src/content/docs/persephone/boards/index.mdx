A **board** is a small app in a folder: an HTML page plus optional scripts. Persephone opens it in
a tab like any other page. Your AI agent can write a board, open it, click through it, fix what it
finds, and hand you a tool that already works.

## Core features

- **Just a folder.** `index.html` with your own CSS and JavaScript. There's no build step, no framework and no server.
- **Real backend scripts.** `.js`, `.py`, `.ps1` and `.sh` scripts run on your machine. Persephone ships Node, so JavaScript works without installing anything.
- **One bridge.** `window.persephone` runs scripts, reads and writes files, and opens results in other editors.
- **Built and tested by the agent.** Through the MCP server it creates, opens, clicks, screenshots and reloads the board until it works.
- **Boards as editors.** A board can claim `*.xlsx`, `*.drawio` or `*.db`, and Persephone offers it next to the built-in editors.
- **Safe by default.** A board runs only after you trust it, and it gets only the permissions it declares, such as running programs, file access or network. Catalog downloads are checksum-verified.

## What you can build

- **A dashboard** for your build, your tickets or your server logs.
- **A viewer** for a file format nothing else opens.
- **A project helper** that deploys, seeds a database or cleans up a folder in one click.
- **A personal tool**: a todo list, a tracker or a report that stores its data next to it.

## Try it

- **Ask your agent:** "make me a todo list that stores its data in the board folder."
- **Do it yourself:** in the **Explorer**, click **Boards**, then **New board**. The caret next to
  it creates a full **Demo board** to explore.
- **Install one** from the [board catalog](/boards/).
