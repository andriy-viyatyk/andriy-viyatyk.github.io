**Persephone** starts like a notepad and opens almost anything: JSON, CSV, logs, Markdown, Word,
Excel, PDF, SQLite, archives. It is also a workspace you share with your AI agent — everything you
see on screen, the agent can see and drive too.

<DemoClip src="persephone-platform.mp4" poster="persephone-platform.jpg" controls caption="A notepad on the outside, a platform on the inside: built-in editors, folders as workspace tabs, and a custom viewer an AI agent builds on request" />

## Core features

- **20+ built-in editors** — code (Monaco, 50+ languages), JSON/CSV grids, Markdown, Mermaid, SVG,
  HTML, images, audio/video, archives, diffs, notebooks, drawings and a REST client.
- **[Workspaces](/persephone/workspace/)** — open a project folder in a tab with its own Explorer,
  project-wide search and the project's boards.
- **More on demand** — the [board catalog](/boards/) installs Word, Excel, PowerPoint, PDF, draw.io
  and SQLite viewers ([how installing works](/persephone/boards/installing/)).
- **Built-in MCP server** — one `call` tool exposes the whole app to your AI agent ([ai-vision](/ai-vision/)).
- **[Boards](/persephone/boards/)** — small apps your agent builds, opens and tests for you.
- **Web browser** — profiles, incognito, Tor, bookmarks; the agent can drive web pages too, and learn
  the sites you use daily with [site extensions](/persephone/site-extensions/).
- **Scripting** — JavaScript/TypeScript with full Node.js access to transform any page.
- **Also inside** — Git graph and diffs, encrypted files, Mneme agent memory (optional).

## What you can do with it

- **Open whatever you were sent.** Logs, a ZIP, a `.docx`, a database — no hunting for the right app.
- **Make sense of data.** Paste a JSON array or CSV, sort and filter it as a grid, copy it to Excel.
- **Test an API.** Keep request collections in a `.rest.json` file next to your code.
- **Get answers you can read.** Your agent opens a sortable grid, a diagram or rendered Markdown
  instead of pasting walls of text into the chat.
- **Get a tool built in a coffee break.** Ask your agent for a dashboard, a report viewer or a
  viewer for an odd file format — it builds it as a board and checks that it works.
- **Automate the boring part.** A few lines of script reformat, split or merge what is on screen.
- **Work in the browser with your agent.** It reads, clicks and fills in pages in Persephone's
  browser while you watch.
- **Keep notes, links and sketches** in one place, encrypted when needed.
