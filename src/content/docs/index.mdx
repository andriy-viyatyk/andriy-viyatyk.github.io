## Why Persephone

- **One app for every file.** Code, JSON, CSV, logs, Markdown, diagrams, archives, plus Word, Excel, PDF and SQLite on demand.
- **Your AI agent works in it with you.** It opens grids, diagrams and documents to show you results, and it drives the app and the browser.
- **Tools built on request.** Ask for a dashboard or a viewer, and the agent builds it as a board and tests it.
- **Free, open source and local.** It runs on Windows and collects no usage data.
